# 00. 오리엔테이션 — 무엇을 만들었나

## 한 줄 요약
회의록을 붙여넣으면 AI가 정리·저장하고, 물어보면 과거 회의를 **RAG로 찾아 출처와 함께** 답하며, 액션을 **담당자별 간트**로 추적하는 웹앱.

## 핵심 개념 (왜)
- **문제:** 팀이 회의록을 남겨도 과거 결정·맥락을 다시 못 찾고, 같은 논의를 반복하고, 액션이 추적되지 않는다.
- **해결:** 회의록을 "회사의 기억"으로 누적 → 자연어로 물으면 **근거(출처)와 함께** 답하고, 액션은 간트로 가시화.
- **핵심 가치:** "물어보면 답한다" — 단순 저장이 아니라 **검색·교차점검**이 핵심.

## 우리가 한 것 (전체 그림)
**스택**
| 영역 | 기술 | 역할 |
|---|---|---|
| 백엔드 | FastAPI · psycopg · pydantic-settings | API·DB 연결 |
| AI | CLOVA Studio(임베딩+HyperCLOVA X) · CLOVA Speech(STT) | 정리·답변·음성 |
| 저장 | PostgreSQL + **pgvector** | 회의·벡터·액션 |
| 프론트 | React(UMD + Babel standalone, 빌드 없음) | 4화면 SPA |
| 배포 | Docker Compose · Ncloud Server · Caddy(HTTPS) | 운영 |

**4화면:** 입력 → ① RAG 검색 → ② 액션 보드(간트) → ③ 누적 대시보드

**아키텍처(최종)**
```
[브라우저] ─HTTPS→ [Caddy] → [FastAPI] ─내부망→ [pgvector(docker)]
                                  ├→ CLOVA Studio (임베딩·답변)
                                  └→ CLOVA Speech (STT)
```

## 막혔던 점 → 해결 (이 가이드에서 다룰 주제들)
- AI 출력 JSON 파싱, 임베딩 차원 → **01·02장**
- 교차점검이 안 떴다 → **03장**
- STT 502, 캐시로 수정 미반영, 간트 압축 → **04·05장**
- 배포 SSH·도커 데몬·줄바꿈 → **07·08장**
- 비밀값 누출 방지 → **09장**
